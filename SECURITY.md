# Security Policy

## Supported Versions

This repo tracks a single `main` branch. Only the latest commit is supported.

## Reporting a Vulnerability

If you find a security issue in one of these skills (e.g. a script that could execute unsafe code, mishandle credentials, or process untrusted input unsafely), please report it privately rather than opening a public issue.

Report it to [@mykemiller-DCI](https://github.com/mykemiller-DCI) via a [GitHub security advisory](https://github.com/mykemiller-DCI/Skills-Repository/security/advisories/new) or a direct message.

Please include:
- The affected skill/folder and file
- Steps to reproduce
- Potential impact

We'll acknowledge reports as soon as possible and follow up with a fix or mitigation timeline.
