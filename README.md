# Skills Repository

Claude skills for consulting work: engineering, data, and design research.

## Skills

| Skill | Description |
|---|---|
| [`engineering-architecture`](engineering-architecture/) | Create or evaluate an Architecture Decision Record (ADR) — document a design decision with trade-offs and consequences, or review a system design proposal. |
| [`engineering-system-design`](engineering-system-design/) | Design systems, services, and architectures — requirements gathering, API design, data modeling, and service boundaries. |
| [`data-analyze`](data-analyze/) | Answer data questions, from a quick metric lookup to a full trend investigation or a formal stakeholder report. |
| [`data-build-dashboard`](data-build-dashboard/) | Build a self-contained, interactive HTML dashboard with charts, filters, and tables — no server or dependencies required. |
| [`design-research-synthesis`](design-research-synthesis/) | Synthesize user research (interviews, surveys, usability tests, support tickets) into themes, insights, and prioritized recommendations. |
| [`xlsx`](xlsx/) | Create, edit, and analyze Excel spreadsheets (`.xlsx`, `.xlsm`, `.xltx`, `.csv`, `.tsv`). |

## Usage

Each folder is a self-contained skill with its own `SKILL.md`. Drop a folder into your Claude skills directory to make it available.
